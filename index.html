💡 Cara Dapat URL Firebase Gratis (1 Menit):
  1. Buka console.firebase.google.com → klik Create a project.
  2. Di menu kiri pilih Build → Realtime Database → Create Database.
  3. Pilih lokasi server → pilih Start in test mode → salin link URL database (`https://...firebasedatabase.app`) ke kolom di atas.
